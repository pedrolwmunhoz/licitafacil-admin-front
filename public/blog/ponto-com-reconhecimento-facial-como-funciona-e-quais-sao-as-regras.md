# Ponto com reconhecimento facial: como funciona e quais são as regras

O ponto com reconhecimento facial utiliza uma câmera e um sistema de processamento de imagem para identificar ou autenticar o funcionário no momento do registro da jornada.

Em vez de utilizar cartão, senha ou impressão digital, o sistema utiliza características da face para verificar a identidade do trabalhador e associar a marcação ao seu cadastro.

A tecnologia pode ser utilizada em equipamentos de ponto, computadores, tablets e dispositivos móveis, dependendo da arquitetura da solução.

Quando características faciais são tratadas com a finalidade de identificar ou autenticar uma pessoa, estamos diante do tratamento de dados biométricos. Pela LGPD, o dado biométrico vinculado a uma pessoa natural é classificado como dado pessoal sensível.

Por isso, o ponto com reconhecimento facial envolve duas questões diferentes: **o registro da jornada** e **o tratamento dos dados biométricos utilizados no reconhecimento**.

## O que é ponto com reconhecimento facial?

É um sistema de controle de jornada que utiliza características da face do funcionário para realizar sua identificação ou autenticação durante a marcação do ponto.

O processo normalmente envolve uma câmera e um software capaz de analisar características faciais e compará-las com uma referência cadastrada para o trabalhador.

De forma simplificada:

**funcionário → câmera → análise facial → identificação → registro do ponto**

Depois da identificação, o sistema registra a marcação correspondente à jornada.

A tecnologia pode ser utilizada para registrar:

* entrada;
* saída;
* início do intervalo;
* retorno do intervalo;
* outras marcações previstas pelo sistema.

O reconhecimento facial participa da identificação do trabalhador. Ele não substitui as demais etapas necessárias para o registro e o tratamento da jornada.

## Como funciona o reconhecimento facial no ponto?

Antes de utilizar o sistema, o funcionário precisa ser cadastrado.

Dependendo da tecnologia, o cadastro pode envolver a captura de imagens e o processamento de características da face para criar uma referência utilizada posteriormente pelo sistema.

No momento da marcação, a câmera captura a face do funcionário.

O sistema processa as características necessárias para realizar a comparação e verifica se existe correspondência com o cadastro.

Quando a identificação ou autenticação é concluída, a marcação da jornada é registrada.

Um fluxo simplificado pode ser:

1. cadastro do funcionário;
2. captura dos dados necessários para o reconhecimento;
3. criação ou armazenamento da referência utilizada pelo sistema;
4. captura da face durante a marcação;
5. processamento das características faciais;
6. comparação;
7. identificação ou autenticação;
8. registro da jornada;
9. armazenamento e tratamento da marcação.

A arquitetura exata depende do sistema utilizado.

## Reconhecimento facial é biometria?

Sim, **quando características da face são tratadas para identificar ou autenticar uma pessoa**.

Nesse contexto, o reconhecimento facial é uma tecnologia utilizada para tratar características biométricas.

A ANPD trata o reconhecimento facial como uma das tecnologias utilizadas para o tratamento de dados biométricos e cita características como o formato da face entre os atributos que podem ser utilizados para reconhecimento automatizado.

É importante, porém, não confundir qualquer fotografia com dado biométrico.

Uma fotografia, isoladamente, não deve ser automaticamente classificada como dado pessoal sensível. A ANPD explica que imagens podem se tornar relacionadas ao tratamento de dados biométricos quando são processadas para extrair atributos biométricos com finalidade de identificação.

A classificação pode ser entendida assim:

**imagem/fotografia → processamento de características faciais → identificação ou autenticação → dado biométrico → dado pessoal sensível, quando vinculado a uma pessoa natural**

Essa distinção é importante para entender as obrigações de proteção de dados envolvidas no ponto com reconhecimento facial.

## Ponto com reconhecimento facial é obrigatório?

Não existe uma obrigação geral para que as empresas utilizem reconhecimento facial no registro de ponto.

A regulamentação do controle eletrônico de jornada estabelece requisitos para os sistemas de registro eletrônico, atualmente classificados pelo Ministério do Trabalho em REP-C, REP-A e REP-P. As modalidades manual e mecânica de controle de jornada também permanecem previstas.

O reconhecimento facial é uma tecnologia que pode ser utilizada em uma solução de registro de ponto.

Por isso, é necessário separar:

* obrigação de realizar o controle de jornada, quando aplicável;
* utilização de registro eletrônico;
* tipo de REP utilizado;
* tecnologia utilizada para identificar o trabalhador.

Uma empresa pode utilizar registro eletrônico de ponto sem utilizar reconhecimento facial.

## A Portaria 671 exige reconhecimento facial?

Não.

A Portaria nº 671/2021 regulamenta os sistemas de registro eletrônico de ponto, mas não estabelece o reconhecimento facial como requisito geral para registrar a jornada eletronicamente.

O Ministério do Trabalho atualmente reconhece três tipos de registradores eletrônicos de ponto:

* REP-C;
* REP-A;
* REP-P.

O próprio MTE explica que o REP-P permite o uso de novas tecnologias, incluindo marcação de ponto por dispositivos móveis.

Isso significa que **reconhecimento facial e REP são conceitos diferentes**.

**REP** é uma categoria regulamentar de registrador eletrônico de ponto.

**Reconhecimento facial** é uma tecnologia que pode ser utilizada para identificar o trabalhador.

Portanto, uma solução pode utilizar reconhecimento facial sem que essa tecnologia seja uma exigência geral da Portaria 671.

## Reconhecimento facial pode ser usado no REP-P?

O REP-P é o Registrador Eletrônico de Ponto via Programa, uma das categorias de registrador eletrônico previstas na regulamentação atual.

O MTE explica que o REP-P permite a utilização de novas tecnologias para registro de ponto, incluindo dispositivos móveis.

Isso permite que uma solução baseada em software utilize diferentes dispositivos como coletores de marcação, conforme sua arquitetura e os requisitos regulamentares aplicáveis.

Um dispositivo com câmera pode, portanto, fazer parte de uma solução que utilize reconhecimento facial.

Isso não significa que todo REP-P tenha reconhecimento facial.

A tecnologia de identificação depende da solução desenvolvida.

## Reconhecimento facial é diferente de biometria?

Não exatamente.

**Reconhecimento facial pode ser uma forma de utilização da biometria.**

O termo biometria é mais amplo e engloba características físicas, fisiológicas ou comportamentais utilizadas para reconhecer ou autenticar pessoas.

Entre os exemplos estão:

* impressão digital;
* características da face;
* íris;
* retina;
* voz;
* outras características utilizadas para identificação.

A ANPD trata reconhecimento facial como uma das tecnologias relacionadas ao tratamento de dados biométricos.

Portanto:

**biometria → conceito mais amplo**

**reconhecimento facial → tecnologia que utiliza características faciais para reconhecimento ou autenticação**

Para uma abordagem mais ampla sobre sistemas biométricos de ponto, veja [ponto eletrônico com biometria](/blog/ponto-eletronico-com-biometria-como-funciona-e-quais-sao-as-regras).

## Reconhecimento facial evita que outra pessoa bata o ponto?

Um dos objetivos de utilizar reconhecimento facial no ponto pode ser aumentar a associação entre a marcação e o trabalhador identificado.

Em um sistema baseado apenas em cartão, crachá ou senha, existe a possibilidade de outra pessoa utilizar aquele identificador.

Com o reconhecimento facial, o sistema busca verificar a identidade do indivíduo no momento da marcação.

Isso pode dificultar situações de compartilhamento de cartões, senhas ou outros identificadores.

Entretanto, o reconhecimento facial não deve ser tratado como garantia absoluta contra qualquer fraude.

O resultado depende de fatores como:

* qualidade da câmera;
* condições de iluminação;
* qualidade do cadastro;
* algoritmo utilizado;
* configuração do sistema;
* mecanismos de proteção contra tentativas de fraude;
* procedimentos adotados quando ocorre uma falha de reconhecimento.

A ANPD também aponta que sistemas biométricos e de reconhecimento facial podem apresentar riscos relacionados a erros de identificação e outros impactos sobre os titulares.

## O que acontece quando o rosto não é reconhecido?

Um sistema de ponto com reconhecimento facial precisa considerar situações em que a identificação não seja concluída.

Isso pode acontecer por diferentes motivos:

* iluminação inadequada;
* câmera com baixa qualidade;
* posição do rosto;
* obstruções;
* alterações significativas na aparência;
* problemas no dispositivo;
* falha de comunicação;
* erro do sistema de reconhecimento.

A empresa precisa definir como o funcionário poderá registrar a jornada nesses casos.

Dependendo da solução, pode existir outro método de identificação ou um procedimento alternativo para realizar a marcação.

Isso é importante porque uma falha no reconhecimento facial não deve simplesmente resultar na ausência do registro da jornada.

## Reconhecimento facial e LGPD

Esse é um dos principais pontos jurídicos de um sistema de ponto facial.

A LGPD classifica como **dado pessoal sensível** o dado biométrico vinculado a uma pessoa natural. A ANPD utiliza essa mesma classificação em seus materiais e documentos técnicos.

Quando uma empresa utiliza reconhecimento facial para identificar funcionários, portanto, precisa considerar as regras aplicáveis ao tratamento de dados pessoais sensíveis.

Isso envolve aspectos como:

* finalidade do tratamento;
* hipótese legal;
* necessidade;
* transparência;
* segurança;
* controle de acesso;
* armazenamento;
* compartilhamento;
* retenção;
* eliminação;
* atendimento aos direitos dos titulares.

A ANPD também destaca que o tratamento de dados biométricos apresenta riscos específicos relacionados à privacidade, segurança e aos direitos dos titulares.

## É preciso consentimento para usar reconhecimento facial no ponto?

Não é correto afirmar que todo sistema de reconhecimento facial para controle de jornada necessariamente depende de consentimento.

A LGPD estabelece hipóteses específicas para o tratamento de dados pessoais sensíveis. A empresa precisa analisar qual hipótese legal é aplicável ao tratamento realizado.

O consentimento é uma das hipóteses previstas para o tratamento de dados pessoais sensíveis, mas não é a única.

Além disso, quando o tratamento ocorre no contexto de uma relação de trabalho, a análise precisa considerar a finalidade, a necessidade do tratamento e as circunstâncias concretas da operação.

Por isso, a empresa deve avaliar juridicamente o tratamento realizado antes de implementar o reconhecimento facial.

## A empresa pode armazenar a foto do funcionário?

Depende da forma como o sistema funciona.

Uma solução pode trabalhar com diferentes arquiteturas para realizar o reconhecimento facial.

A empresa precisa saber quais informações são efetivamente coletadas e armazenadas.

Existe uma diferença entre armazenar uma fotografia e utilizar essa imagem para extrair e tratar características biométricas com finalidade de identificação.

A ANPD explica que fotografias e imagens não são automaticamente dados pessoais sensíveis apenas por serem imagens. A classificação como dado biométrico sensível está relacionada ao tratamento de atributos biométricos para identificação.

Por isso, ao contratar um sistema de ponto facial, é importante verificar:

* quais dados são coletados;
* se imagens são armazenadas;
* se existe geração de referência ou template biométrico;
* onde os dados ficam armazenados;
* quem possui acesso;
* por quanto tempo permanecem armazenados;
* se existe compartilhamento com terceiros;
* como ocorre a eliminação;
* quais medidas de segurança são utilizadas.

## O que é um template biométrico?

Em sistemas de reconhecimento facial, o sistema pode processar características da face e gerar uma representação utilizada posteriormente para comparação.

Essa representação é frequentemente chamada de **template biométrico**.

Ela não precisa ser uma fotografia convencional do funcionário.

O sistema pode utilizar informações matemáticas ou outras representações derivadas das características faciais para realizar a comparação.

A arquitetura varia conforme a tecnologia.

Por isso, ao avaliar um sistema de ponto facial, é importante descobrir se a solução armazena fotografias, templates biométricos ou ambos.

Independentemente da arquitetura, quando há tratamento de características biométricas para identificar ou autenticar uma pessoa, devem ser consideradas as regras aplicáveis aos dados biométricos.

## Reconhecimento facial e segurança dos dados

A segurança precisa ser analisada em toda a cadeia do sistema.

Um sistema pode possuir reconhecimento facial eficiente e ainda apresentar riscos caso os dados sejam armazenados ou transmitidos de maneira inadequada.

Entre os aspectos técnicos que podem ser avaliados estão:

* criptografia;
* controle de acesso;
* autenticação;
* segregação de dados;
* logs;
* proteção das APIs;
* segurança do dispositivo;
* proteção do armazenamento;
* gestão de credenciais;
* política de retenção;
* procedimentos para incidentes.

A ANPD destaca que o tratamento de dados biométricos apresenta riscos específicos e que esses dados exigem atenção especial em razão de sua natureza.

## Reconhecimento facial funciona sem internet?

Depende da solução.

Alguns sistemas podem executar determinadas etapas localmente no dispositivo e sincronizar os registros posteriormente.

Outros dependem de comunicação com o servidor para realizar a identificação ou registrar a marcação.

Por isso, **ter reconhecimento facial não significa automaticamente que o ponto funciona offline**.

São características independentes.

Uma solução pode ter:

* reconhecimento facial online;
* reconhecimento facial com funcionamento offline;
* ponto online sem reconhecimento facial;
* ponto offline sem reconhecimento facial.

Para entender especificamente essa questão, veja [ponto eletrônico offline](/blog/ponto-eletronico-offline-como-funciona-quando-nao-ha-internet).

## Reconhecimento facial pode ser usado pelo celular?

Sim, dependendo da solução.

Um smartphone possui câmera e capacidade computacional para executar diferentes formas de identificação facial.

Em uma solução de ponto baseada em aplicativo, o celular pode funcionar como coletor da marcação.

Nesse cenário, o funcionário utiliza o aplicativo, realiza a identificação e registra a jornada.

O uso de reconhecimento facial, entretanto, depende da implementação do sistema.

Um aplicativo de ponto não possui reconhecimento facial simplesmente por funcionar em um celular.

Veja também [app de ponto eletrônico](/blog/app-de-ponto-eletronico-como-funciona-e-como-usar).

## Reconhecimento facial pode ter geolocalização?

Pode.

Os dois recursos possuem finalidades diferentes.

O reconhecimento facial está relacionado à **identificação do trabalhador**.

A geolocalização está relacionada à **localização associada à marcação**.

Uma solução pode combinar os dois recursos:

**reconhecimento facial → identificação do trabalhador**

**geolocalização → localização associada à marcação**

Mas nenhum dos dois recursos deve ser confundido com o próprio registro da jornada.

Veja [geolocalização no ponto](/blog/geolocalizacao-no-ponto-como-funciona-e-para-que-serve) para entender esse recurso separadamente.

## Reconhecimento facial substitui o comprovante de ponto?

Não.

O reconhecimento facial é utilizado durante a identificação do trabalhador.

O comprovante de registro é outra parte do sistema de registro eletrônico de ponto.

A Portaria 671 estabelece requisitos próprios para o comprovante de registro de ponto. Nos sistemas eletrônicos, o comprovante pode ser disponibilizado em formato eletrônico e deve seguir os requisitos previstos na regulamentação.

Portanto, a imagem utilizada no reconhecimento facial ou o resultado da identificação não substitui o comprovante correspondente à marcação.

O funcionário continua tendo acesso às informações de suas marcações conforme as regras aplicáveis ao sistema utilizado.

## Reconhecimento facial substitui o espelho de ponto?

Também não.

O reconhecimento facial participa da identificação durante a marcação.

O espelho de ponto é produzido posteriormente a partir dos registros da jornada tratados pelo sistema.

Um fluxo simplificado é:

**face → identificação → marcação → registro → tratamento → espelho de ponto**

A Portaria 671 estabelece que o Programa de Tratamento de Registro de Ponto trata os dados das marcações e gera o Espelho de Ponto Eletrônico e o Arquivo Eletrônico de Jornada.

Assim, a tecnologia utilizada para identificar o funcionário não elimina as demais etapas do controle da jornada.

Veja [AFD, AEJ e espelho de ponto](/blog/o-que-e-afd-e-aej).

## Ponto facial é a mesma coisa que ponto por biometria?

Quando o reconhecimento facial é utilizado para identificar ou autenticar o trabalhador, ele está dentro do conceito de biometria.

A diferença está na especificidade dos termos.

**Ponto biométrico** pode utilizar diferentes características biométricas.

**Ponto facial** especifica que a característica utilizada é a face.

Assim, um sistema de ponto com reconhecimento facial pode ser considerado um sistema de ponto biométrico, mas um sistema biométrico não necessariamente utiliza reconhecimento facial.

Ele também pode utilizar impressão digital ou outra característica biométrica.

## Ponto com reconhecimento facial é seguro?

A segurança depende da implementação.

O reconhecimento facial pode reduzir a dependência de cartões, senhas ou outros identificadores que podem ser compartilhados, mas também cria requisitos específicos relacionados à proteção dos dados biométricos.

A ANPD aponta riscos associados a erros de reconhecimento, segurança da informação e impactos sobre os titulares no uso de tecnologias biométricas.

Por isso, a análise de uma solução deve considerar simultaneamente:

* segurança do registro de ponto;
* segurança do dispositivo;
* segurança da transmissão;
* armazenamento dos dados;
* controle de acesso;
* proteção da biometria;
* procedimentos para falhas.

## Como escolher um sistema de ponto com reconhecimento facial?

Antes de contratar um sistema, é importante verificar como a tecnologia funciona na prática.

### Como o funcionário é cadastrado?

Verifique como ocorre a captura inicial da face e quais dados são armazenados.

### O sistema armazena imagens?

Essa informação ajuda a entender quais dados efetivamente são tratados.

### Existe template biométrico?

Verifique se o sistema gera uma representação das características faciais e como ela é armazenada.

### O reconhecimento funciona offline?

Se a empresa possui locais com internet instável, essa característica pode ser relevante.

### Existe método alternativo?

É importante saber como o funcionário registra o ponto quando o reconhecimento facial falha.

### Como os dados são protegidos?

Avalie armazenamento, transmissão, acesso, criptografia e controles de segurança.

### Como funciona a LGPD?

A empresa deve compreender a finalidade, a hipótese legal e os demais aspectos relacionados ao tratamento dos dados biométricos.

### O sistema atende às regras do registro eletrônico de ponto?

A tecnologia facial não substitui os requisitos aplicáveis ao sistema de registro eletrônico utilizado.

## Reconhecimento facial no controle de jornada

O reconhecimento facial pode ser utilizado como mecanismo de identificação dentro de um sistema de controle de jornada.

A tecnologia permite associar uma marcação ao trabalhador por meio do processamento de características da sua face, mas isso não elimina as demais etapas do registro e tratamento da jornada.

Também existe uma camada específica de proteção de dados.

Quando características faciais são tratadas para identificar ou autenticar uma pessoa, o tratamento envolve dados biométricos. Quando vinculados a uma pessoa natural, esses dados são classificados pela LGPD como dados pessoais sensíveis.

A ANPD também destaca que o reconhecimento facial pode apresentar riscos relacionados à privacidade, segurança e erros de identificação, o que exige atenção especial ao tratamento dessas informações.

Por isso, uma empresa que pretende utilizar ponto com reconhecimento facial precisa avaliar conjuntamente:

* a tecnologia de identificação;
* o sistema de registro de jornada;
* a segurança das informações;
* o tratamento dos dados biométricos;
* os procedimentos para falhas de reconhecimento;
* a hipótese legal aplicável;
* e as obrigações previstas na legislação de proteção de dados.

O reconhecimento facial é uma tecnologia de identificação que pode fazer parte de um sistema de ponto eletrônico. Ele não substitui o próprio sistema de registro de jornada nem as obrigações relacionadas ao tratamento dos dados dos funcionários.
